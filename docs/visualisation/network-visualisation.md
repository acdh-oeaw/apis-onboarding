# Network visualisation

Exported data can be visualised as an interactive network graph, via the
[`django-cosmograph`](https://github.com/acdh-oeaw/django-cosmograph) plugin: entities
become nodes, relations become edges. Plotting the data this way surfaces patterns that
aren't visible row by row: which places were most active, which works were most copied,
how a network of people and texts changed over time. This is the same kind of question
raised in [Research questions and historical
sources](../introduction/research-questions.md).

The graph can be scoped to any combination of entity and relation types: from a single
relation type across the whole dataset down to one project's view of how two of its
entity types connect.
