# Zotero references

## The apis-bibsonomy plugin

[`apis-bibsonomy`](https://github.com/acdh-oeaw/apis-bibsonomy) lets entities and
relations cite a bibliographic reference directly, rather than as free text.

## Importing references from a Zotero group library

References are imported by searching a linked Zotero group library while editing a
record:

![Searching a linked Zotero library for a reference while editing a
record](../assets/images/web-app/zotero-references.png)

Once imported, a reference behaves like any other linked record: it can be attached to
several entities or relations, and stays in sync with the group library it came from.
