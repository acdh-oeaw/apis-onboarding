# Entering relationships

## New relation

A relation can be created from the standard form for that relation type, with a Subject
and an Object field:

![A standalone "Create" form for a relation, with Subject "Sebastian Beer" and Object
"Freudenthaler Hinteregger e.V."](../assets/images/web-app/relation-entry-form.png)

## From the subject or object entity

A relation can be created also from the detail view of an entity.

![A Person's page with relation-type buttons like "is a member of" and "works for"; one is
clicked open to pick the other
entity](../assets/images/web-app/relation-entry-inline.png)

[`apis-highlighter-ng`](https://github.com/acdh-oeaw/apis-highlighter-ng) lets you
annotate information directly within a block of running text, creating entities and
relations from the highlighted passage.

## By annotating

Relations can be creating by highlighting relevant parts of a text that is the source of information for the relation.

![Selecting a name in a running biographical text opens a form to record the relation it
describes](../assets/images/web-app/text-annotation.png)
