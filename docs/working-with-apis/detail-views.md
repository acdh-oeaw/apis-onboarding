# Detail views

Every entity's detail page shows its relations grouped by type, from that entity's point
of view (as subject or as object). The layout varies a little by project. Here are three
examples:

![A Work's detail page, with its attributes on the left and its relations — grouped into
All / Instance / Person / Place / Work tabs — on the
right](../assets/images/web-app/detail-view-work.png)

![A Place's detail page listing every Work that is a "place of copy of" this
place](../assets/images/web-app/detail-view-place.png)

![A detail page grouping relation types under labelled buttons such as "inventory",
"organization", "career" and "places", with the relations already recorded listed below
each group](../assets/images/web-app/detail-view-relation-buttons.png)
