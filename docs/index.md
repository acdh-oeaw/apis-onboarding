# APIS onboarding

APIS (Austrian Prosopographical Information System) is a data management
system, that is primarily developed to allow data collection for prosopographic
research. It is a framework that allows one to create web applications to
manage both entities and relations between entities and by that model and
explore complex historical data. This site is a self-paced guide for
project partners and researchers onboarding an APIS project. It covers what prosopography is, how
to turn historical sources into structured data, how to design a data model, and how to use the 
APIS instance for data entering, retrieval and research.
