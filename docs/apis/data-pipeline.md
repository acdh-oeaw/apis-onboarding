# The APIS data pipeline

Every APIS instance moves data through the same four stages, regardless of its own data
model or which optional plugins it has added:

1. **Data modelling** define entities, relations and controlled vocabularies. Covered
   separately in [Data modelling](../modelling/introduction.md), since it is different for every project.
2. **Data ingestion and curation** enter data manually, or import it from authority
   files, spreadsheets, XML, images and texts; enrich and correct it over time. Covered in
   [Working with APIS](../working-with-apis/data-entry.md).
3. **Filtering** search and filter every field, on every entity and relation type.
   Covered in [Searching, filtering and managing data](../search/filtering.md).
4. **Export** export data for dissemination, visualisation, or use in external tools.
   Covered in [Exporting data](../search/export.md) and [Exploring and visualising
   data](../visualisation/network-visualisation.md).
