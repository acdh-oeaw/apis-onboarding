## Filtering entities

Every field on every entity type is searchable, including custom fields and date ranges:

![A filtered list of entities, with search fields for every attribute down the left-hand
side](../assets/images/web-app/filtering-entities.png)

The search fields adapt to whatever attributes that entity type has. An Inscription
record exposes fields like preservation state and material instead:

![A filtered list of Inscription records, with search fields for preservation state,
material and distribution, and results including transliterated Arabic
text](../assets/images/web-app/filtering-inscriptions.png)

## Filtering relationships

Relations can be filtered the same way entities can: by type, by the entities they
connect, by date, and by any extra information the relation carries. A relation's
confidence value, for instance, shows up as a filterable
column anywhere that relation is listed:

![A filtered list of relations with a Certainty column, showing values like "high" and
"unknown"](../assets/images/web-app/filtering-relations-certainty.png)
